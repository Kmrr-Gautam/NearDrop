<h2 align="center">🚀 Building & Running</h2>

<details open>
<summary><b>📱 1. Android Application</b></summary>

<br/>

**Prerequisites**
- Android Studio Ladybug or newer
- JDK 17 or 21
- Android SDK 34 (minSdk 26, Android 8.0+)

**Install on device**
1. Download [`neardrop-v0.2.3.apk`](https://github.com/Kmrr-Gautam/NearDrop/raw/main/release/neardrop-v0.2.3.apk) directly to your Android device.
2. Tap the downloaded file to install and open NearDrop.

**Build from source**

```bash
# Clone the repository
git clone https://github.com/Kmrr-Gautam/NearDrop.git
cd NearDrop

# Run test suite
./gradlew testDebugUnitTest

# Build debug APK
./gradlew assembleDebug

# Build production release APK
./gradlew assembleRelease
```

The compiled APK will be generated at `app/build/outputs/apk/release/`.

</details>

<details>
<summary><b>☁️ 2. FastAPI Backend (<code>neardrop-backend/</code>)</b></summary>

<br/>

**Prerequisites**
- Python 3.11 or newer

**Setup & run**

```bash
cd neardrop-backend

# Create virtual environment
python -m venv venv
# Linux / macOS:
source venv/bin/activate
# Windows:
.\venv\Scripts\activate

# Install pinned dependencies
pip install -r requirements.txt

# Configure environment
cp .env.example .env

# Run database migrations
alembic upgrade head

# Start Uvicorn development server
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

**Interactive documentation**
- **Swagger UI:** `http://127.0.0.1:8000/docs`
- **ReDoc:** `http://127.0.0.1:8000/redoc`

**Run backend tests**

```bash
pytest
```

</details>
